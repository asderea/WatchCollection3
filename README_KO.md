# Watch Collection v1.32.0

개인 시계 컬렉션, 위시리스트, 착용 캘린더, 오차·파워리저브 측정, 스트랩, 수리 이력, 헤리티지와 컬렉션 사진을 관리하는 Android 앱입니다.


## v1.32.0 주요 변경

### 개인화 컬렉션 평가 프로필
- 이 채팅에서 정리된 현재 취향과 장기 계획을 앱의 초기 평가 프로필로 반영했습니다.
- 기본 프로필에는 기계식 중심 선호, 선호·비선호 다이얼 색상, 목표 8구, 핵심 유지 시계와 장기 위시 우선순위가 포함됩니다.
- `COLLECTION AT A GLANCE → 평가 프로필`에서 내용을 직접 수정하거나 기본값으로 복원할 수 있습니다.
- 프로필은 기기 내부에 저장되고 현재 컬렉션 또는 Wish 컬렉션 평가를 실행할 때만 Worker로 전송됩니다.
- 프로필이나 시계 정보가 바뀌어도 AI를 자동 호출하지 않습니다. 기존 점수에는 `갱신 필요`가 표시되며 `다시 평가`를 눌렀을 때만 크레딧을 사용합니다.
- 현재 컬렉션의 최초 평가와 시계 추가·삭제에 따른 자동 평가 규칙은 유지합니다.

### 컬렉션·Wish 역할 지정
- 모든 현재 시계와 Wish 시계에 `Dress`, `Diver`, `Tool`, `Sports` 중 메인 역할을 필수로 지정할 수 있습니다.
- 보조 역할은 선택 사항이며 메인 역할과 다른 역할 하나를 추가할 수 있습니다.
- 현재 시계는 추가·수정 화면과 시계 상세 페이지의 `역할 설정`에서 변경할 수 있습니다.
- 상세 페이지의 역할 설정 팝업에는 별도의 안내 문구를 넣지 않았습니다.
- Wish 시계는 추가·수정 화면에서 동일한 방식으로 역할을 지정합니다.
- 컬렉션 카드와 Wish 카드, 상세 페이지에 저장된 역할을 표시합니다.

### 컬렉션 필터와 평가 기준
- 컬렉션 필터를 `Power | Brand | Role` 3개로 구성하고 한 줄에 같은 폭으로 배치했습니다.
- Role 필터는 메인 역할과 보조 역할을 모두 검색합니다.
- 컬렉션 평가에는 사용자 프로필과 시계별 역할이 함께 전달됩니다.
- 메인 역할은 주 역할, 보조 역할은 보완 역할로 평가합니다.
- 총점은 앱에서 `역할 다양성 25% + 구성 균형 25% + 중복 관리 20% + 실용성 15% + 장기 완성도 15%`로 다시 계산해 같은 기준을 유지합니다.
- 평가 캐시는 시계 역할·스펙·스트랩·평가 프로필·평가 프롬프트 버전까지 반영해 유효성을 검사합니다.

## v1.31.2 주요 변경

### 케이스백 배경 제거
- 대표사진용 단순 모서리 flood-fill 대신 케이스백 전용 피사체 분리기를 사용합니다.
- ML Kit Subject Segmentation을 먼저 적용하고, 인식 실패 시 다중 모서리 색상·경계 연결성 기반 로컬 분리기로 자동 전환합니다.
- 금속 반사로 생기는 작은 마스크 누락과 회색 halo를 보정합니다.
- 분리된 케이스백을 앱 사진 배경색 위 정사각형 캔버스 중앙에 배치합니다.
- 분리 신뢰도가 낮으면 케이스백을 잘못 잘라내지 않고 방향만 보정한 원본을 유지합니다.
- 기존 Cloudflare Worker와 환경변수는 변경하지 않습니다.
- 기존에 저장된 케이스백은 자동으로 덮어쓰지 않으므로, 새 분리기를 적용하려면 편집 화면에서 같은 사진을 다시 선택합니다.

## v1.31.1 주요 변경

### 캘린더 카드와 착용 순위
- 상단 첫 행에 `WRIST CALENDAR / 착용 캘린더`와 `착장 추천`을 좌우로 정렬했습니다.
- 그 아래 행에서 `TODAY'S WATCH`와 `FORGOTTEN WATCH`가 같은 높이에서 시작하도록 맞췄습니다.
- 착용 순위 카드의 `처음 3개를 표시하며...` 안내 문구를 제거했습니다.
- `TODAY'S WATCH`의 AI 추천 설명을 카드에서 제거하고 고정 높이와 불필요한 아래 여백을 없앴습니다.
- `FORGOTTEN WATCH` 위에 별도의 `착장 추천` 버튼을 추가했습니다.
- 착용 순위는 앱 진입 시 `이번 달`을 먼저 표시합니다.
- 좌우 버튼으로 `이번 달 → 올해 → 누적 → 이번 달` 순서로 순환합니다.
- 각 기간은 처음 세 줄 높이만 보이고 카드 내부를 스크롤하면 전체 순위를 확인할 수 있습니다.
- 누적 순위는 착용 당시 시계명과 사진 스냅샷을 사용하므로 컬렉션에서 삭제한 시계도 계속 남습니다.

### 측정 페이지
- 하단 메뉴의 `오차`를 `측정`으로 변경했습니다.
- 측정 페이지를 `오차 측정`과 `파워리저브 측정`으로 분리했습니다.
- 파워리저브 측정은 `Automatic` 또는 `Mechanical` 시계만 선택할 수 있습니다.
- 측정 시작 후 앱을 닫거나 다른 페이지로 이동해도 진행 상태가 DB에 유지됩니다.
- 진행 중인 시계는 측정 페이지 상단에 표시됩니다.
- 측정 종료 시 시작 시점의 와인딩 상태, 종료 시각, 경과 시간 기반 최소 파워리저브, 메모를 저장합니다.

### 착장 완성 AI
- 상의·하의·신발 중 알고 있는 항목만 입력할 수 있습니다.
- 사용자가 시계와 호환 스트랩을 직접 선택합니다.
- AI는 비어 있는 착장 항목만 추천하며, 결과 아래 피드백을 입력해 다시 추천할 수 있습니다.
- 선택한 시계와 스트랩 이외의 제품은 추천하지 않도록 Worker 구조화 출력으로 제한했습니다.

### 위시리스트
- 컬렉션 헤더에 `Wish` 버튼을 추가하고 기존 추가 버튼은 작은 원형 `+`로 변경했습니다.
- 위시 시계의 모델, 레퍼런스, 작동방식, 주요 크기, 목표 가격, 우선순위, 목표 구매일, 사진과 메모를 저장합니다.
- 각 위시 시계에 현재 컬렉션에서 대체할 시계를 하나 지정할 수 있습니다.
- 하나의 현재 시계는 하나의 위시 항목에만 대체 대상으로 연결됩니다.
- 위시의 대체 대상으로 지정되지 않은 현재 시계만 별도의 방출 후보로 선택할 수 있습니다.
- `Wish 컬렉션 평가` 결과를 DB에 저장하며, 저장 후 버튼에 `점수/100`을 표시합니다.

### AI 컬렉션 평가
- `COLLECTION AT A GLANCE`에서 이번 달 착용일 항목을 제거했습니다.
- 보유 시계, 보유 스트랩, AI 컬렉션 점수를 같은 줄에 배치했습니다.
- 현재 컬렉션 점수를 누르면 전체 점수, 세부 지표별 점수와 이유를 확인할 수 있습니다.
- 세부 지표는 역할 다양성, 구성 균형, 중복 관리, 실용성, 장기 완성도입니다.
- 현재 컬렉션 평가는 최초 1회 또는 시계 추가·삭제로 구성 ID가 바뀐 경우에만 자동 실행합니다.
- 단순 정보 수정, 앱 재실행, 화면 이동만으로는 다시 호출하지 않아 API 크레딧을 절약합니다.
- Wish 평가는 사용자가 버튼을 누를 때만 실행하고 결과를 저장합니다.

### Worker API
- `/api/outfit/complete`: 선택한 시계·스트랩을 기준으로 빈 착장 항목 완성
- `/api/collection/evaluate`: 현재 컬렉션 또는 Wish 반영 예상 컬렉션 평가
- 두 기능 모두 기존 추천용 크레딧 보호 설정을 사용합니다.
- 기존 월별 프로모션 크레딧 자동 주기 계산과 `/api/usage` 게이지 기능을 유지합니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version: `16 → 17`
- 기존 시계, Wish, 스트랩, 착용 기록, 측정 기록과 AI 평가 결과를 유지합니다.
- `watches`와 `wish_watches`에 `main_role`, `secondary_role`을 추가합니다.
- `collection_evaluations`에 멤버십 서명을 추가해 시계 추가·삭제와 단순 정보 변경을 구분합니다.
- 기존 시계와 Wish 항목의 역할은 업데이트 직후 비어 있으며 사용자가 직접 지정할 수 있습니다.

## 적용 순서
1. Cloudflare Worker의 기존 코드를 `ai-backend/worker.js`로 교체하고 Deploy합니다. 새 Variable이나 Secret은 필요하지 않습니다.
2. `.github/workflows/build-apk.yml`을 이용해 GitHub Actions에서 APK를 빌드합니다.
3. 기존 앱 위에 v1.32.0 APK를 설치하면 DB와 기존 데이터가 유지됩니다.
4. 각 시계의 역할을 지정한 뒤 저장된 컬렉션 점수에서 `다시 평가`를 누르면 새 프로필과 역할이 반영됩니다.
