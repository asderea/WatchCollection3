# Changelog

## v1.6.0
- 홈 화면 Watch Calendar 위젯 기본 크기를 4×2로 고정
- 위젯 상단의 WRIST CALENDAR 문구 제거
- 4×2 크기에 맞춰 월 제목, 요일, 날짜 셀, 시계 사진 영역을 컴팩트하게 재배치
- 기존 이전/다음 달 화살표와 착용 시계 사진 표시는 유지
- DB schema 변경 없음

## v1.5.0
- 컬렉션 카드 요약의 Φ / L2L / WR 라벨도 굵게 표시하고 각 제원을 독립 행으로 정리
- 시계 추가/수정 화면의 스펙 정밀 검색 버튼 아래 여백 확대
- Watch Accuracy Meter 자세 선택과 Positional Rate에 전용 시계 자세 벡터 아이콘 적용
- MY WATCHES 컬렉션 사진의 이전/다음 화살표를 사진 위 상단 오버레이로 이동
- 컬렉션 사진을 MY WATCHES 카드 폭에 꽉 차도록 표시 방식 개선
- DB schema 변경 없음, version 8 유지

## v1.4.0
- 홈 화면 위젯 UI를 앱의 착용 캘린더와 유사한 카드형 달력으로 재구성
- 위젯에 일요일 시작 요일 헤더, 월 이동 화살표, 오늘 강조, 착용 시계 사진 최대 2개 표시 추가
- 컬렉션 사진 자동 보정에 배경 분리 + 사다리꼴 원근 보정 + PCA 기반 회전 보정 + 중앙 정렬 적용
- 상세 스펙 팝업을 Hero / Essential / Dimensions / Build / Ownership / Notes 섹션으로 재디자인
- 상세 스펙 값은 각 항목별 한 줄 구조로 분리해 가독성 개선
- DB schema 변경 없음, version 8 유지


## v1.3.0
- 전체 시계 오차 평균 카드를 오차 측정 페이지 최상단으로 이동하고 Rate 평균 그래프를 인라인 표시로 변경
- Rate 평균 그래프 하단 설명 제거
- 컬렉션 카드 요약을 다중 행 구조로 정리하고 Power / Movement / Lug 라벨을 굵게 표시
- 상세 스펙 팝업에서 WR 표기를 Water Resistance로 변경하고 Warranty 관련 보조 설명 제거
- 상세 스펙 및 시계 등록/수정 폼에 구매 가격 입력 추가
- Most Worn / 스트랩 호환 시계 클릭 시 상세 스펙 팝업이 열리도록 변경
- 스트랩 호환 시계 영역의 보조 설명 제거
- 보증 만료 1년 / 6달 / 1달 / 1주일 전 알림 추가
- 컬렉션 사진 업로드, 다중 사진 전환, 팝업 확대, 추가/변경/삭제 기능 추가
- 컬렉션 사진은 자동 배경 정리 및 중앙 정렬 보정 후 표시
- Watch Accuracy Meter 자세 선택 항목에 아이콘형 텍스트 추가
- 홈 화면용 Watch Calendar 위젯(현재 월 달력 텍스트형) 추가
- DB schema version 8로 업데이트 (purchase_price, collection_photos)

- Rate 그래프의 사진/이름/Rate 표시는 유지하면서 실제 막대 영역을 대폭 확대
