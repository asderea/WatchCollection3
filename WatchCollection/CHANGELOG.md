# Changelog

## v1.25.0
- Forgotten Watch 미니 카드의 시계 사진을 확대하고 모델명을 최대 2줄로 표시하여 빈 공간을 줄임
- 헤리티지 페이지 제목을 `시계 연표`에서 `헤리티지`로 변경
- 헤리티지 상단 및 월 제목을 누르면 연도·월 선택 창이 열리도록 추가
- 선택한 연도·월의 헤리티지만 필터링해 보고 전체 기간으로 돌아갈 수 있도록 구현
- 헤리티지 카드 대표사진을 112×112dp 정사각형으로 확대하고 FIT_CENTER로 표시해 잘림 방지
- 헤리티지 추가 사진 미리보기를 정사각형으로 확대
- 헤리티지 상세 사진을 232×232dp 정사각형으로 확대하고 원본 비율을 유지해 표시
- DB schema 변경 없음, version 15 유지

- 앱 기능 및 DB schema 변경 없음

## v1.23.0

- ML Kit Subject Segmentation을 이용해 스트랩 본체, 버클, 두 조각 스트랩을 객체 단위로 분리
- 첫 실행에서 분리 모델이 준비되지 않았거나 인식에 실패하면 모서리 다중 색상·그라데이션·그림자 대응 로컬 분리기로 자동 fallback
- 분리 결과를 투명 PNG로 저장하고 1000×1200 캔버스 중앙에 비율 유지 배치
- 작은 로고·배경 잡티는 제거하되 버클과 분리된 두 조각 스트랩은 유지하도록 연결 요소 정리 강화
- 직접 선택한 사진과 구매 링크에서 받은 상품사진에 동일한 처리 적용
- DB schema 변경 없음, version 15 유지
