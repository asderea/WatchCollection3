# Changelog

## v1.7.0
- 홈 화면 4×2 Watch Calendar 위젯의 착용 시계 사진 크기를 축소하고 기존 앱 착용 캘린더 사진 크기는 유지
- 위젯을 터치하면 Watch Collection의 착용 캘린더 탭으로 바로 열리도록 연결
- 앱/위젯 캘린더의 일요일 날짜·요일은 빨간색, 토요일은 파란색으로 표시
- MY WATCHES의 사진 전환 컨트롤을 사진 밖 상단으로 이동하고, 사진 1장일 때 페이지 번호/화살표를 숨김
- Power / Brand 필터를 MONTHLY WEAR 아래로 이동
- 컬렉션 사진 보정에 큰 전경 연결영역 선별, 기울기 선보정, 원근 보정, 고정 직사각형 캔버스 출력을 적용
- 컬렉션 카드 스펙 요약을 더 컴팩트하게 정리: Φ + L2L 한 줄, Lug Width + WR 한 줄
- 컬렉션 카드의 오차/수정/출처/삭제 버튼을 제거하고 상세 스펙 팝업 안에 수정/출처/삭제를 배치
- MONTHLY WEAR, MOST WORN, 가장 많이 착용한 시계를 누르면 해당 시계 상세 스펙 팝업 표시
- 스트랩 호환 제목을 Lug Width Watch로 변경
- 앱 UI의 '기타' 분류명을 Extra로 변경
- Positional Rate 아이콘 개선: Dial up/down 글라스 표현, 12/9/6/3 Up은 시계 방향을 회전시키되 화살표는 항상 위쪽 표시
- Positional Rate의 3 Up 아래에 시계 대표 사진과 전체 평균 행 추가
- DB schema 변경 없음, version 8 유지

## v1.6.0

- 위젯 상단의 WRIST CALENDAR 문구 제거
- 4×2 크기에 맞춰 월 제목, 요일, 날짜 셀, 시계 사진 영역을 컴팩트하게 재배치
- 기존 이전/다음 달 화살표와 착용 시계 사진 표시는 유지
- DB schema 변경 없음
