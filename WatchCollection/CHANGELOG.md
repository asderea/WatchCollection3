# Changelog

## v1.10.0
- 홈 화면 4×2 위젯: 하루 1개 착용 시 20×20dp, 하루 2개 착용 시 각각 16×16dp로 동적 표시
- 앱 착용 캘린더: 하루 1개 착용 사진은 기존 42×42dp 유지, 하루 2개 착용 시 각각 22×22dp 정사각형으로 축소
- 앱 착용 캘린더의 시계 본체 이미지는 FIT_CENTER로 표시해 잘림/왜곡을 줄임
- 시계 본체 추출 알고리즘 강화: 케이스 폭 프로파일 기반으로 스트랩/브레이슬릿 구간을 더 강하게 제외
- 추출한 시계 본체를 투명 정사각형 캔버스 중앙에 자동 배치
- 기존 v1.9에서 생성된 캘린더 본체 이미지도 새 알고리즘으로 1회 자동 재생성
- DB schema 변경 없음

## v1.10.0
- 4×2 위젯 캘린더: 하루 1개 착용 시 본체 사진 20×20dp, 하루 2개 착용 시 각각 16×16dp로 표시
- 앱 착용 캘린더: 하루 1개 사진은 기존 42dp 유지, 하루 2개는 각각 24×24dp로 축소
- 캘린더용 시계 본체 추출 알고리즘 개선: 케이스/러그 폭 프로파일로 스트랩·브레이슬릿 영역을 분리
- 추출된 시계 본체를 투명 640×640 정사각형 캔버스 중앙에 자동 배치해 앱/위젯에서 정렬 안정화
- 기존 v1.9에서 이미 생성된 캘린더 본체 사진도 v1.10 최초 실행/위젯 갱신 시 새 알고리즘으로 한 번 재생성
- 활성 시계의 새 본체 이미지를 과거 착용 로그 snapshot에도 갱신해, 이후 컬렉션에서 시계를 삭제해도 새 캘린더 사진 유지
- DB schema 변경 없음, version 10 유지

## v1.9.0
- MOST WORN / MONTHLY WEAR 랭킹은 캘린더용 시계 본체 이미지가 아니라 기존 대표 사진을 사용
- 착용 기록이 이미 있는 날짜에서 시계 사진을 눌러도 컬렉션으로 이동하지 않고 날짜 착용 시계 선택 팝업이 열리도록 수정
- 착용 기록에 시계명, 대표 사진, 캘린더용 본체 사진을 스냅샷으로 저장하도록 변경
- 컬렉션에서 시계를 삭제해도 과거 착용 캘린더 로그와 당시 저장된 시계 사진이 유지되도록 wear_records의 ON DELETE CASCADE 의존 제거
- 기존 착용 기록은 v10 마이그레이션에서 현재 시계 정보/사진을 스냅샷으로 보존
- DB schema version 10으로 업데이트

## v1.8.0
- 시계 대표 사진을 가져올 때 캘린더/위젯 전용으로 스트랩을 제외한 시계 본체(러그·케이스·베젤·다이얼 중심) 이미지를 추가 생성
- 앱 착용 캘린더의 월 그리드, 날짜별 착용 팝업, MOST WORN 랭킹에서 전용 시계 본체 이미지를 우선 사용
- 홈 화면 위젯 캘린더도 전용 시계 본체 이미지를 우선 사용
- 기존 DB의 대표 사진이 이미 저장되어 있는 시계도 앱 실행 시 전용 캘린더 이미지를 자동 생성하도록 보완
- 위젯 갱신 시에도 누락된 캘린더 이미지가 있으면 자동 생성 후 반영
- DB schema version 9로 갱신: watches.calendar_image_url 추가

## v1.7.0
- 홈 화면 4×2 Watch Calendar 위젯의 착용 시계 사진 크기를 축소하고 기존 앱 착용 캘린더 사진 크기는 유지
- 위젯을 터치하면 Watch Collection의 착용 캘린더 탭으로 바로 열리도록 연결
- 앱/위젯 캘린더의 일요일 날짜·요일은 빨간색, 토요일은 파란색으로 표시
- MY WATCHES의 사진 전환 컨트롤을 사진 밖 상단으로 이동하고, 사진 1장일 때 페이지 번호/화살표를 숨김
- Power / Brand 필터를 MONTHLY WEAR 아래로 이동
- 컬렉션 사진 보정에 큰 전경 연결영역 선별, 기울기 선보정, 원근 보정, 고정 직사각형 캔버스 출력을 적용
- 컬렉션 카드 스펙 요약을 더 컴팩트하게 정리: Φ + L2L 한 줄, Lug Width + WR 한 줄
- 컬렉션 카드의 오차/수정/출처/삭제 버튼을 제거하고 상세 스펙 팝업 안에 수정/출처/삭제를 배치
- MONTHLY WEAR, MOST WORN, 가장 많이 착용한 시계를 누르면 해당 시계 상세 스펙 팝업 표시
- 스트랩 호환 제목을 Lug Width Watch로 변경
- 앱 UI의 '기타' 분류명을 Extra로 변경
- Positional Rate 아이콘 개선: Dial up/down 글라스 표현, 12/9/6/3 Up은 시계 방향을 회전시키되 화살표는 항상 위쪽 표시
- Positional Rate의 3 Up 아래에 시계 대표 사진과 전체 평균 행 추가
- DB schema 변경 없음, version 8 유지
