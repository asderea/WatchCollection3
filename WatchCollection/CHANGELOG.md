# Changelog

## v1.1.0
- Watch Accuracy Meter 오차 기록 개별 삭제 기능 추가
- 삭제 후 평균/자세별 평균 자동 재계산
- 오차 화면 상단 설명 및 외부 측정 연동 설명 제거
- 자세별 평균의 n=측정횟수 표기 제거
- 전체 시계 Rate 평균 팝업 상단에 사진/이름/Rate 막대 그래프 추가
- Rate 평균 팝업 정렬: |Rate| 작은 순 → 무기록 시계 → 무기록 중 착용횟수 많은 순
- 컬렉션 수량 제한 없이 Monthly Wear를 3개 단위로 전체 순위 페이지 처리
- 컬렉션 Power / Brand 필터를 Spinner 드롭다운으로 변경, 기본 All / All
- Brand의 `전체 브랜드` 표기를 `All`로 변경
- 스트랩 Lug width / Material 이중 드롭다운 필터 추가
- Material 선택값: Leather / Bracelet / Rubber / Nato / Mesh / 기타
- 호환 러그폭 시계를 전체 착용횟수 내림차순으로 정렬
- DB schema 변경 없음, version 7 유지
