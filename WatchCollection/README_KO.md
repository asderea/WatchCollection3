# Watch Collection v0.5

개인 시계 컬렉션, 오차 기록, 착용 캘린더, 스트랩 라이브러리를 한 앱에서 관리하는 Android 앱입니다.

## v0.5 핵심 변경

### 1. 무료/독립형 스펙 검색 엔진 대폭 강화
- 모델명/브랜드/레퍼런스를 분리해 검색합니다.
- 레퍼런스 번호를 구두점 제거형, 지역 suffix 변형까지 정규화합니다.
- Bing RSS + Bing HTML + DuckDuckGo Lite를 조합하고, 일본 브랜드는 Yahoo Japan을 추가 사용합니다.
- 후보가 부족할 때만 Google HTML 검색을 보조적으로 시도합니다.
- 제조사 공식 sitemap을 직접 탐색해 검색엔진이 놓친 공식 제품 URL을 찾습니다.
- 공식 페이지가 사라진 단종 모델은 Internet Archive의 공식 페이지 아카이브를 보조 탐색합니다.
- 공식/고신뢰 DB/전문 매체/판매처를 신뢰도 단계로 구분합니다.
- 페이지의 레퍼런스/브랜드/모델 토큰을 다시 검증한 뒤 정확한 모델로 확인된 페이지만 스펙 추출에 사용합니다.
- HTML 본문 외에도 title/meta description, JSON-LD Product, additionalProperty, Next.js/Nuxt/Shopify 형태의 embedded JSON을 함께 읽습니다.
- 영어/한국어/일본어/일부 독일어 스펙 라벨을 지원합니다.
- Casio/Orient의 L×W×H 표기, Mido/Tissot의 Width/Length/Lugs 같은 제조사별 표기도 보강했습니다.
- 공식 출처 또는 복수 출처가 합의한 값만 자동 채택하며, 확인이 부족한 필드는 빈칸으로 둡니다.
- 대표 사진은 자동 검색하지 않고 사용자가 직접 선택합니다.

### 2. 착용 캘린더
- 날짜를 누르면 착용 시계 선택 UI가 하단이 아니라 팝업으로 열립니다.
- 하루 최대 2개 시계를 기록할 수 있습니다.
- 1개 착용은 1회, 2개 착용은 각 0.5회로 통계에 반영합니다.
- 캘린더 상단 TOP 3 랭킹 카드는 캘린더와 같은 폭으로 표시됩니다.
- 랭킹 카드의 좌/우 버튼으로 `올해`와 `이번 달` TOP 3를 전환합니다.
- 랭킹 또는 날짜의 시계 사진을 누르면 해당 시계의 컬렉션 카드로 이동합니다.

### 3. 스트랩
- 18 / 19 / 20 / 21 / 22 mm 외 규격을 위한 `기타` 탭을 추가했습니다.
- 스트랩 등록 시 첫 정보 입력란으로 `스트랩 제작사`를 추가했습니다.
- 스트랩 카드에 제작사와 폭을 함께 표시합니다.
- 18~22 mm 탭에서는 해당 러그 폭의 보유 시계를 대표사진/이름으로 최상단에 표시합니다.
- `기타`는 폭이 특정되지 않으므로 자동 호환 시계는 표시하지 않습니다.

## 데이터 마이그레이션
DB 버전은 4입니다. 기존 v0.4 데이터는 유지되며, 스트랩 테이블에 제작사 필드가 자동 추가됩니다.
