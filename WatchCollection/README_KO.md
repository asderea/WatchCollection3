# Watch Collection v1.26

개인 시계 컬렉션, 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 수리 이력, 헤리티지와 컬렉션 사진을 관리하는 Android 앱입니다.

## v1.26 주요 변경

### 헤리티지 보존
- 헤리티지는 시계 ID뿐 아니라 저장 당시의 시계명과 대표사진을 스냅샷으로 보관합니다.
- 컬렉션에서 해당 시계를 삭제하더라도 기존 헤리티지는 삭제되지 않습니다.

### Watch Details의 Heritage
- Repair History 아래에 Heritage 섹션이 추가됩니다.
- 해당 시계와 연결된 헤리티지의 날짜와 제목을 최신순으로 표시합니다.
- 날짜 또는 제목을 누르면 헤리티지 페이지로 이동하고 해당 기록 상세창이 열립니다.

### 컬렉션 외 시계 기록
- 헤리티지 추가 창의 시계 선택 목록에서 `직접 시계명 입력`을 선택할 수 있습니다.
- 컬렉션에 없는 시계도 사용자가 입력한 이름으로 날짜, 제목, 내용, 사진을 저장할 수 있습니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 15 유지
- 기존 시계, 스트랩, 착용 기록, 오착 사진, 수리 이력, 헤리티지, 오차 기록 유지
