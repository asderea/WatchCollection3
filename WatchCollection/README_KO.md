# Watch Collection v1.17

개인 시계 컬렉션, Watch Accuracy Meter 기반 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 컬렉션 사진과 수리 이력을 관리하는 Android 앱입니다.

## v1.16 주요 변경

### 오착 사진
- 착용 캘린더에서 날짜를 누른 뒤 하단 `오착` 버튼으로 착용 사진을 추가합니다.
- 한 장 또는 여러 장을 동시에 선택할 수 있습니다.
- 하루 두 시계를 착용한 경우 `시계를 선택하세요` 창에서 어느 시계의 사진인지 지정합니다.
- 날짜별 오착 사진 관리 창과 시계 상세 페이지에서 사진을 확대하거나 개별 삭제할 수 있습니다.
- 시계 상세 페이지의 `오착` 버튼에서는 날짜 최신순으로 해당 시계의 착용 사진을 확인합니다.

### 스펙 검색 진행 로그
- `스펙 정밀 검색` 아래에 모델 분석, 레퍼런스 확인, 검색 질의 처리, 후보 검증, 스펙 추출, 교차검증 진행 상태를 순서대로 표시합니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 12
- 기존 시계, 사진, 착용 기록, 스트랩, 오차, 수리 이력 데이터 유지

## 빌드
저장소 루트에 `.github/workflows/build-apk.yml`을 만들고 제공된 workflow 전체를 붙여넣어 GitHub Actions에서 빌드합니다.


## v1.17 오착 사진 방향 보정
오착 사진을 선택하면 촬영 기기의 EXIF 방향값을 실제 픽셀에 반영하여 저장합니다. 기존에 저장된 오착 사진도 앱에서 표시할 때 방향을 보정합니다.
