# Watch Collection v1.18

개인 시계 컬렉션, Watch Accuracy Meter 기반 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 컬렉션 사진, 케이스백 사진과 수리 이력을 관리하는 Android 앱입니다.

## v1.18 주요 변경

### 오착 갤러리
- 컬렉션의 시계별 오착은 최신 날짜를 기본으로 한 날짜별 갤러리로 표시합니다.
- 날짜 좌우 화살표로 다른 날짜로 이동하고, 사진 위 좌우 화살표로 같은 날짜의 여러 사진을 넘깁니다.
- 날짜 버튼을 누르면 오착 사진이 있는 날짜만 활성화된 전용 달력이 열립니다.
- 착용 캘린더의 오착 관리도 해당 날짜의 사진을 한 장씩 표시하고 좌우 화살표로 이동합니다.
- 현재 사진 삭제를 지원하며 삭제 즉시 DB와 내부 파일에서 제거합니다.

### 케이스백 사진
- 시계 등록/수정 화면에서 케이스백 사진을 직접 추가·원본 복구·삭제할 수 있습니다.
- 케이스백 사진은 EXIF 방향을 보정하고 대표사진과 같은 `#FCFBF7` 배경으로 정리합니다.
- 컬렉션 카드와 Watch Details의 시계 사진을 누르면 3D 회전 효과로 앞면/케이스백이 전환됩니다.
- 케이스백이 없는 경우 Watch Details의 케이스백 영역에 추가 버튼이 표시됩니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 13
- 기존 시계, 사진, 착용 기록, 오착, 스트랩, 오차, 수리 이력 데이터 유지
