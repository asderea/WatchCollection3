# Watch Collection v1.2

개인 시계 컬렉션, 착용 캘린더, 스트랩, 자세별 오차 기록을 관리하는 Android 앱입니다.

## v1.2 주요 변경

### 착용 캘린더
- 월간 캘린더가 항상 6주(42칸)를 강제로 표시하지 않도록 수정했습니다.
- 해당 월에 실제로 필요한 4~6주만 생성하여 캘린더 하단의 불필요한 빈 공간을 줄였습니다.
- 날짜 셀 높이와 세로 여백도 소폭 축소했습니다.
- 일요일 시작 방식과 하루 2개 착용/0.5회 집계는 그대로 유지합니다.

### 오차 측정
- MEASUREMENT SETUP의 시계 선택 목록을 **전체 착용 횟수 많은 순**으로 정렬합니다.
- Watch Accuracy Meter 결과 입력 팝업의 시계 선택 목록도 동일한 순서를 사용합니다.
- 착용 횟수가 같으면 Brand → Model 순으로 정렬합니다.

### 전체 시계 Rate 평균 그래프
- 기존의 이름 옆 좁은 고정폭 그래프를 제거했습니다.
- 시계별로 `작은 사진 + 이름 + Rate`를 위에 표시하고, 그 아래에 **팝업 가로 폭 대부분을 사용하는 넓은 Rate 그래프**를 표시합니다.
- 0 s/day 중앙선 기준의 +/- 막대 구조와 기존 Rate 정렬 기준은 유지합니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 7 유지
- 기존 시계/사진/착용/스트랩/오차 데이터 유지
- 이번 버전은 DB 스키마 변경 없음

## 빌드
저장소 루트에 `.github/workflows/build-apk.yml`을 별도로 만들고 제공된 workflow를 붙여넣어 GitHub Actions에서 빌드합니다.


## v1.4 추가
- Watch Calendar 홈 화면 위젯은 앱 착용 캘린더와 비슷한 일요일 시작 월간 레이아웃을 사용합니다. 날짜 칸에 착용 대표 사진을 최대 2개 표시하고 좌우 화살표로 월을 이동할 수 있습니다.
- 컬렉션 사진은 업로드 후 배경 분리, 원근 사다리꼴 보정, 자동 회전 보정, 중앙 정렬을 순서대로 시도합니다. 복잡한 사진에서는 안전을 위해 일부 단계가 생략될 수 있습니다.
- 상세 스펙 팝업은 Essential / Dimensions / Build / Ownership로 구분합니다.
