# Watch Collection v0.8

개인 시계 컬렉션, 마이크 기반 타임그래퍼 오차 측정, 착용 캘린더, 스트랩 라이브러리를 한 앱에서 관리하는 Android 앱입니다.

## v0.8 핵심 변경

### 1. 약한 신호 대응 Timegrapher 엔진 v2
기존 v0.7의 단일 high-pass + 보수적 threshold 방식에서 측정 엔진을 크게 변경했습니다.

- 3개 주파수 대역을 동시에 분석합니다.
  - 약 320~1,300 Hz
  - 약 850~3,000 Hz
  - 약 1,800~6,200 Hz
- 시계/휴대폰 조합에서 가장 잘 잡히는 대역을 sample마다 자동 선택합니다.
- 500 Hz로 다운샘플한 envelope history에 autocorrelation을 적용해 beat 주기를 먼저 찾습니다.
- 다음 일반 BPH 후보를 동시에 비교합니다.
  - 18,000
  - 19,800
  - 21,600
  - 25,200
  - 28,800
  - 36,000 bph
- autocorrelation 점수와 실제 tick/tock 이벤트 간격 일치도를 합쳐 BPH를 결정합니다.
- 같은 BPH 후보가 반복 확인되면 `LOCK` 상태로 전환합니다.
- BPH가 Lock되면 다음 beat 예상 시점 주변에서는 threshold를 자동으로 낮춰 약한 tick/tock을 더 적극적으로 추적합니다.
- 몇 개의 beat를 놓쳐도 2~6 beat 간격을 허용해 회귀에 다시 연결합니다.
- Android `AudioTimestamp`가 제공되는 기기에서는 실제 audio sample clock을 이용해 rate 계산을 보정합니다.
- 휴대폰의 일반 `MIC` 입력을 우선 사용하고, 초기화 불가 시 `UNPROCESSED`로 fallback합니다.

### 2. 더 빠른 측정 표시 / 저장
- 약 2~4초부터 BPH 및 Rate 잠정값을 표시하도록 변경했습니다.
- BPH가 확정되면 화면에 `LOCK`이 표시됩니다.
- 최소 8초, 18개 이상의 유효 beat, 신호 품질 20% 이상이면 Save가 활성화될 수 있습니다.
- 15~30초 이상 계속 측정하면 회귀 데이터가 더 쌓여 값이 안정화됩니다.
- 신호가 약해도 BPH/Rate/Beat Error는 가능한 범위에서 계속 계산합니다.
- Amplitude는 escapement impulse 내부 구조가 충분히 선명할 때만 표시하고, 불확실하면 `-`로 유지합니다.

### 3. 자세별 오차를 '최근값'이 아닌 '평균'으로 표시
아래 6개 자세별로 저장된 전체 측정값의 평균을 계산합니다.

- Dial up
- Dial down
- 12 Up
- 9 Up
- 6 Up
- 3 Up

각 자세마다 다음을 표시합니다.
- 평균 Rate (s/day)
- 평균 Beat Error (ms)
- 평균 Amplitude (가능한 기록만)
- 측정 횟수 `n`

같은 자세를 여러 번 측정할수록 해당 자세의 평균값이 갱신됩니다.

### 4. 시계별 오차 한눈에 보기 팝업
- 컬렉션의 각 시계 카드에 `오차` 버튼을 추가했습니다.
- 오차 탭의 선택 시계에서도 `선택 시계 오차 한눈에 보기` 버튼을 사용할 수 있습니다.
- 팝업에서 다음을 한 화면에 확인합니다.
  - 전체 평균 Rate
  - 평균 Beat Error
  - 평균 Amplitude
  - 총 저장 측정 횟수
  - 6개 자세별 평균 Rate / Beat Error / 측정 횟수
  - 최근 측정 6개

### 5. 기존 v0.7 기능 유지
- 수동 오차 입력 UI 없음
- 측정 후 자세 선택 저장
- Lift angle 설정
- Timegrapher trace / signal quality
- 대표 사진 선택 즉시 배경 `#FCFBF7` 자동 통일
- 대표 사진 원본 별도 보관 / 원본 복구
- 컬렉션 착용 횟수순 기본 정렬
- 브랜드 필터
- Monthly Wear 1~5위 / 6~10위 전환
- 일요일 시작 착용 캘린더
- 하루 2개 시계 착용 시 각각 0.5회
- 스트랩 18/19/20/21/22 mm + 기타 / 제작사 저장

## 데이터 보존
- `applicationId`: `com.watchcollection.app` 유지
- 기존 debug 서명키 유지
- DB 버전은 v0.7과 동일한 5이며, 이번 업데이트는 스키마 변경이 없습니다.
- 기존 시계/스펙/사진/착용/스트랩/타임그래퍼 측정값은 그대로 유지됩니다.
- 기존 앱을 삭제하지 않고 v0.8 APK를 **업데이트 설치**해야 데이터가 유지됩니다.

## 측정 팁
- 시계를 충분히 감은 상태에서 측정하세요.
- 약한 신호에서도 추적하도록 개선했지만, 가능하면 크라운/케이스를 휴대폰 마이크 가까이에 두는 것이 유리합니다.
- 전문 contact microphone timegrapher보다 휴대폰 마이크는 주변 소음과 기기별 오디오 처리의 영향을 더 받습니다.
- Amplitude 정확도를 높이려면 해당 칼리버의 Lift angle을 입력하세요.
