# Watch Collection v1.21

개인 시계 컬렉션, 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 수리 이력과 컬렉션 사진을 관리하는 Android 앱입니다.

## v1.21 주요 변경

### 범용 상품 정보 추출
- 특정 쇼핑몰 이름에 맞춘 전용 파서가 아니라 페이지에 존재하는 여러 상품 데이터 후보를 함께 평가합니다.
- JSON-LD Product, 임베디드 상품 JSON, 공유 문구, H1, itemprop, Open Graph, Twitter Card 및 본문을 교차검증합니다.
- 상품명·브랜드·레퍼런스·대표사진 후보에 출처별 점수를 부여합니다.
- 네이버 스토어, 스마트스토어, 쇼핑, Store 등의 플랫폼 이름은 상품명이나 제작사로 확정하지 않습니다.
- 로고·파비콘·배너·프로필 이미지 후보를 제외하고 실제 상품사진을 우선합니다.
- 첫 사진 후보가 유효하지 않으면 다음 후보를 자동으로 확인합니다.

### Android 공유 메뉴 연동
- 브라우저나 쇼핑 앱에서 `공유`를 누른 뒤 `Watch Collection`을 선택할 수 있습니다.
- 공유 페이지가 시계 상세 페이지로 판단되면 컬렉션 추가 화면을 열고 스펙 정밀 검색을 자동 실행합니다.
- 스트랩/브레이슬릿 구매 페이지로 판단되면 스트랩 추가 화면을 열어 상품 정보와 사진을 자동 반영합니다.
- 분류가 애매하면 시계 또는 스트랩 중 추가 위치를 직접 선택할 수 있습니다.

### 스트랩 사진 처리
- 실제 상품사진 후보를 최대 6개까지 순차 확인합니다.
- 너무 작거나 배너처럼 극단적인 비율의 이미지는 제외합니다.
- 선택된 상품사진은 EXIF 방향 보정과 배경 정리를 거쳐 앱 내부에 저장됩니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 14 유지
- 기존 시계, 스트랩, 착용 기록, 오착 사진, 수리 이력, 오차 기록 유지
