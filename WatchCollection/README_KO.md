# Watch Collection v1.25

개인 시계 컬렉션, 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 수리 이력, 헤리티지와 컬렉션 사진을 관리하는 Android 앱입니다.

## v1.25 주요 변경

### Forgotten Watch 카드
- 캘린더 상단의 Forgotten Watch 카드에서 대표사진을 확대했습니다.
- 시계 이름은 최대 2줄까지 표시해 카드 하단의 빈 공간을 줄였습니다.
- 미착용 일수와 마지막 착용일은 기존처럼 함께 표시합니다.

### 헤리티지 연도·월 선택
- 헤리티지 페이지 제목을 `헤리티지`로 통일했습니다.
- 상단 기간 선택 버튼이나 각 월 제목을 누르면 연도와 월을 지정할 수 있습니다.
- 선택한 월의 기록만 볼 수 있으며 `전체 기간`으로 다시 전환할 수 있습니다.

### 헤리티지 사진 표시
- 헤리티지 목록 대표사진을 112×112dp 정사각형으로 표시합니다.
- 사진 추가 미리보기와 상세 사진도 정사각형으로 확대했습니다.
- 모든 헤리티지 사진은 FIT_CENTER로 표시해 세로 사진이나 가로 사진이 잘리지 않도록 했습니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 15 유지
- 기존 시계, 스트랩, 착용 기록, 오착 사진, 수리 이력, 헤리티지, 오차 기록 유지
