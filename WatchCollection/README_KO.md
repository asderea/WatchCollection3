# Watch Collection v1.20

개인 시계 컬렉션, Watch Accuracy Meter 기반 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 컬렉션 사진, 케이스백 사진과 수리 이력을 관리하는 Android 앱입니다.

## v1.20 주요 변경

### 구매 링크 기반 스트랩 추가
- 스트랩 추가/수정 창의 첫 항목에 `구매 링크`를 추가했습니다.
- `링크에서 정보 가져오기`를 누르면 상품 페이지의 공개 HTML, Open Graph, JSON-LD Product 정보를 확인합니다.
- 확인 가능한 경우 다음 값을 자동 입력합니다.
  - 스트랩 제작사
  - 상품명
  - 러그 폭 18 / 19 / 20 / 21 / 22 mm
  - 색상
  - 재질: Leather / Bracelet / Rubber / Nato / Mesh / Extra
  - 버클 유형
  - 상품 설명
  - 대표사진
- 자동 입력된 값은 저장 전 직접 수정할 수 있습니다.
- 로그인, JavaScript 렌더링 또는 봇 차단이 필요한 쇼핑몰은 일부 정보가 비어 있을 수 있습니다.

### 스트랩 사진 자동 보정
- 구매 링크에서 가져온 대표사진은 앱 내부로 복사한 뒤 배경을 `#FCFBF7`로 정리합니다.
- 사용자가 직접 선택한 스트랩 사진도 동일한 배경 보정을 적용합니다.
- EXIF 회전 정보를 픽셀에 반영한 뒤 저장합니다.
- 복잡한 배경으로 안전하게 분리할 수 없는 경우 사진을 훼손하지 않고 원본을 유지합니다.

### 구매 링크 보관
- 스트랩 DB에 구매 링크를 함께 저장합니다.
- 스트랩 카드의 `구매 링크` 버튼으로 원래 상품 페이지를 다시 열 수 있습니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 14
- v1.19의 기존 시계, 사진, 착용 기록, 오착, 스트랩, 오차, 수리 이력 데이터 유지
