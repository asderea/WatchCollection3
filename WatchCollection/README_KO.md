# Watch Collection v1.23

개인 시계 컬렉션, 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 수리 이력, 헤리티지 연표와 컬렉션 사진을 관리하는 Android 앱입니다.

## v1.23 주요 변경

### 스트랩 전용 배경 제거
- 스트랩 사진에 시계 대표사진용 단색 배경 제거기를 재사용하지 않고, 스트랩 전용 하이브리드 분리기를 적용합니다.
- Google ML Kit Subject Segmentation으로 스트랩 본체, 버클, 두 조각 스트랩을 피사체 단위로 분리합니다.
- 분리 모델이 아직 준비되지 않았거나 인식에 실패하면 다중 모서리 색상, 그라데이션, 그림자를 고려하는 로컬 분리기로 자동 전환합니다.
- 분리 결과는 투명 PNG로 저장하고 1000×1200 캔버스 중앙에 비율을 유지해 배치합니다.
- 작은 배경 잡티는 제거하되 버클이나 분리된 스트랩 조각은 유지합니다.

### 적용 범위
- 사용자가 직접 선택한 스트랩 사진
- 구매 링크에서 내려받은 상품 대표사진
- 공유 메뉴로 전달된 스트랩 상품 사진
- 기존 스트랩 수정 화면의 `배경 다시 제거` 기능

### 범용 상품 정보 추출
- JSON-LD Product, 임베디드 상품 JSON, 공유 문구, H1, itemprop, Open Graph, Twitter Card 및 본문을 교차검증합니다.
- 플랫폼 이름, 로고, 파비콘, 배너, 판매자 프로필 이미지를 상품명·대표사진 후보에서 제외합니다.

### Android 공유 메뉴 연동
- 브라우저나 쇼핑 앱에서 `공유`를 누른 뒤 `Watch Collection`을 선택할 수 있습니다.
- 시계 상세 페이지는 컬렉션 추가, 스트랩 구매 페이지는 스트랩 추가 화면으로 연결됩니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 15 유지
- 기존 시계, 스트랩, 착용 기록, 오착 사진, 수리 이력, 헤리티지, 오차 기록 유지

## 참고
- ML Kit 피사체 분리 모델은 Google Play services를 통해 준비됩니다.
- 모델이 준비되기 전이거나 Google Play services를 사용할 수 없는 기기에서는 앱의 로컬 배경 분리기가 자동으로 사용됩니다.

## 빌드
저장소 루트의 `.github/workflows/build-apk.yml`에 제공된 workflow를 붙여넣어 GitHub Actions에서 빌드합니다.
