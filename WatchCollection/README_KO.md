# Watch Collection v1.7

개인 시계 컬렉션, Watch Accuracy Meter 기반 오차 기록, 착용 캘린더, 스트랩, 컬렉션 사진을 관리하는 Android 앱입니다.

## v1.7 주요 변경

### 컬렉션
- MY WATCHES의 여러 사진 전환 버튼/페이지 번호를 사진 밖 상단에 배치합니다. 사진이 1장이면 전환 UI를 표시하지 않습니다.
- 컬렉션 사진은 배경 분리 후 큰 전경을 우선 추적하고, 회전 기울기 → 원근 왜곡 순으로 보정한 뒤 고정 직사각형 캔버스에 저장합니다.
- Power / Brand 필터는 MONTHLY WEAR 아래에 표시합니다.
- 시계 카드의 Φ + L2L, Lug Width + WR을 각각 같은 줄에 표시해 카드 높이를 줄였습니다.
- 카드의 수정/출처/삭제 버튼은 제거하고 상세 스펙 팝업 안으로 이동했습니다.
- MONTHLY WEAR, MOST WORN 및 가장 많이 착용한 시계에서 시계를 누르면 상세 스펙 팝업이 열립니다.

### 오차
- Dial up / Dial down 아이콘은 측면 시계 + 글라스 표현으로 개선했습니다.
- 12 / 9 / 6 / 3 Up은 시계 본체 방향만 회전하고 방향 화살표는 항상 위를 향합니다.
- 3 Up 아래에 대표 사진과 전체 평균 Rate 행을 표시합니다.

### 캘린더 / 위젯
- 기존 앱 착용 캘린더 사진 크기는 변경하지 않았습니다.
- 4×2 위젯의 착용 시계 사진만 더 작게 표시합니다.
- 앱/위젯 모두 일요일은 빨간색, 토요일은 파란색으로 표시합니다.
- 위젯의 달력 영역을 누르면 앱의 착용 캘린더 탭으로 바로 이동합니다.

### 스트랩
- Lug width 호환 시계 제목을 `Lug Width Watch`로 변경했습니다.
- UI의 `기타` 분류는 `Extra`로 통일했습니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 8 유지
- 기존 시계/사진/컬렉션 사진/착용 기록/스트랩/오차 기록 유지
