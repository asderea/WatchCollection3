# Watch Collection v0.3

개인 시계 컬렉션, 오차, 착용 기록, 스트랩을 한 앱에서 관리하는 Android 앱입니다.

## v0.3 핵심 변경

### 1. 시계 검색 품질 대폭 개선
- 제조사 공식 도메인을 최우선 검색합니다.
- Citizen `BM1350-54A`, Seiko `SPB519`, Hamilton `H70405730`처럼 레퍼런스 형식을 감지해 브랜드를 자동 추정합니다.
- 검색 결과마다 시계 관련성 점수를 계산합니다.
- Facebook/YouTube/Reddit/Amazon/GitHub 등 스펙 출처로 부적합한 도메인은 제외합니다.
- 공식 사이트가 아니면 시계 전문 사이트 또는 레퍼런스 강한 일치 결과만 후보로 허용합니다.
- 검색 스니펫만 믿지 않고 실제 페이지 본문에서 모델명/레퍼런스 일치를 한 번 더 검증합니다.
- 서로 다른 검색 결과를 한 덩어리로 섞지 않고, 공식 페이지 → 신뢰 출처 순으로 필드별 스펙을 채웁니다.
- 직경/두께/러그 폭/파워리저브에는 비정상 숫자를 걸러내는 범위 검사를 적용합니다.
- 대표사진은 공식 제조사 페이지의 Product JSON-LD 또는 `og:image` / `twitter:image`에서만 가져옵니다.
- 저장되는 출처 URL도 관련성 검증을 통과한 최대 4개만 남깁니다.
- 시계 추가 화면에서 브랜드와 레퍼런스를 검색 힌트로 직접 넣을 수 있습니다.

### 2. 컬렉션
- 하단 탭에 아이콘 추가
- 시계 카드에 `올해 착용 횟수`, `이번 달 착용 횟수`, `전체 착용 횟수` 표시
- 캘린더/스트랩/착용 TOP3에서 시계를 누르면 해당 시계가 컬렉션 최상단에 강조되어 표시

### 3. 착용 캘린더
- 캘린더 상단에서 가로 스와이프로 `올해 TOP 3` / `이번 달 TOP 3` 확인
- TOP3에 대표사진, 모델명, 착용 횟수 표시
- 하루에 최대 시계 2개 기록 가능
- 하루 1개 기록: 해당 시계 1.0회
- 하루 2개 기록: 각 시계 0.5회
- 캘린더 날짜 셀에 최대 두 개의 시계 대표사진을 나란히 표시
- 날짜에 표시된 시계 사진을 누르면 해당 컬렉션으로 바로 이동

### 4. 스트랩
- 18 / 19 / 20 / 21 / 22 mm 필터
- 특정 mm 탭을 선택하면 페이지 최상단에 해당 러그 폭의 보유 시계를 대표사진 + 모델명으로 가로 표시
- 호환 시계를 누르면 컬렉션의 해당 시계로 이동
- 스트랩 사진, 색상, 재질, 버클/특징, 메모 저장

## 데이터 마이그레이션
DB 버전은 3입니다. v0.2의 기존 착용 기록은 자동으로 `slot 1` 기록으로 옮겨지며 기존 시계/오차/스트랩 데이터는 유지됩니다.

## APK 업데이트 서명
`app/watchcollection-debug.keystore`를 프로젝트에 포함해 v0.3 이후 GitHub Actions 빌드가 같은 debug 서명을 사용하도록 했습니다. 따라서 이후 v0.4, v0.5 APK는 기존 앱 위에 덮어설치하면서 앱 내부 DB를 유지할 수 있습니다. 이 키는 개인용 debug 빌드 전용이며 Play Store release 서명에는 사용하지 마세요.

## 빌드
프로젝트의 `.github/workflows/build-apk.yml`에서 GitHub Actions로 debug APK를 생성할 수 있습니다.

1. 이 ZIP의 **내용물 전체를 저장소 루트에** 업로드합니다. ZIP 바깥에 `WatchCollection` 폴더를 한 번 더 만들지 않는 것이 중요합니다.
2. 저장소 루트 구조가 `.github/`, `app/`, `build.gradle`, `settings.gradle` 형태인지 확인합니다.
3. Actions에서 `Build Watch Collection APK`를 실행합니다.
4. 성공 후 `WatchCollection-v0.3-debug-apk` artifact를 받습니다.

## 참고
웹사이트 구조/접근 정책 때문에 공식 페이지를 읽지 못하는 모델은 자동 추출이 실패할 수 있습니다. v0.3은 이 경우 관련 없는 페이지에서 억지로 값을 채우기보다 빈 값으로 남기는 쪽을 우선합니다.
