# Watch Collection v1.19

개인 시계 컬렉션, Watch Accuracy Meter 기반 오차 기록, 착용 캘린더, 오착 사진, 스트랩, 컬렉션 사진, 케이스백 사진과 수리 이력을 관리하는 Android 앱입니다.

## v1.19 주요 변경

### 컬렉션 카드 앞면 / 케이스백
- Watch Details에 들어가지 않아도 컬렉션 카드의 시계 사진을 누르면 앞면과 케이스백이 3D 플립 효과로 전환됩니다.
- 시계 사진 클릭과 상세 스펙 열기 동작을 분리했습니다.
- 상세 스펙은 카드의 이름과 정보 영역을 눌러 엽니다.

### 오착 갤러리
- 같은 날짜의 여러 오착 사진을 넘기는 좌우 화살표를 사진 안쪽의 반투명 오버레이 버튼으로 변경했습니다.
- 날짜 버튼은 `달력 · YYYY-MM-DD`로 표시됩니다.
- 날짜 버튼을 누르면 전체 월 달력이 열리고, 해당 시계의 오착 사진이 있는 날짜만 활성화됩니다.
- 활성화된 날짜를 누르면 그 날짜의 해당 시계 오착 사진으로 바로 이동합니다.
- 최신 오착 날짜가 기본 선택됩니다.

### 오차 측정
- 오차 페이지 최초 진입 시 어떤 시계도 선택되지 않은 상태로 시작합니다.
- 시계를 선택하기 전에는 측정 버튼과 결과 입력 버튼이 비활성화됩니다.
- 최근 측정에는 현재 선택한 시계의 기록만 표시됩니다.

### 스트랩
- 러그 폭 필터를 선택했을 때 호환 시계 영역의 제목과 안내 문구를 제거했습니다.
- 각 스트랩 카드에는 실제 호환되는 시계 이름이 직접 표시됩니다.

## 데이터 유지
- applicationId: `com.watchcollection.app` 유지
- 동일 debug 서명키 유지
- DB version 13 유지
- 기존 시계, 사진, 착용 기록, 오착, 스트랩, 오차, 수리 이력 데이터 유지
